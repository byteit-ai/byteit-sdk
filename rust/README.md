# ByteIt SDK for Rust

A Rust SDK is available on request. Write to
[support@byteit.ai](mailto:support@byteit.ai) with your use case and we will set
you up.

The ByteIt API is a standard HTTPS REST API, so it can also be called from
Rust directly. [ENDPOINTS.md](../ENDPOINTS.md) lists every operation with
its route, and the SDKs below show each call in full:

- [Python](../python)
- [TypeScript / JavaScript](../typescript)
- [C# / .NET](../dotnet)
